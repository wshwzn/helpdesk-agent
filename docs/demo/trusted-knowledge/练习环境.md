# 独立练习环境

用途是自己理解和复现问答流程，支撑口头交流；不需要为面试建设展示页面。

## 初始化与重复执行

```powershell
python -X utf8 scripts/prepare_knowledge_practice.py --activate
```

管理员认证沿用 `HELPDESK_ADMIN_USERNAME`、`HELPDESK_ADMIN_PASSWORD`，或指定被 Git 忽略的 `--auth-file`。默认连接本地 8080；脚本正常注册一个随机用户名的 CUSTOMER 账号，密码随机生成，不打印，也不写入仓库文档。

- 本地账号信息：`target/knowledge-practice/customer-credentials.json`。
- 库 ID、资料 ID、准备进度与前一个默认库：`target/knowledge-practice/state.json`。
- 原始运行日志和验证输出均在 `target/` 下。不要把这个目录提交或发送给他人。

相同 output 重复运行会复用账号、库和已就绪资料，先核验内容摘要、业务元数据和状态，不重新上传/索引。发现已撤回的文件、未知文档或配置被更改时停止，不覆盖人工修改。可恢复已记录的准备进度；上传成功但进度文件未保存等不确定中断需要人工检查，不能盲目声称任意故障下恰好一次。

只有显式 `--activate` 才会将全部准备成功的库设为默认。没有开启时仅准备环境。客户账号隔离自己的会话，知识库仍是全局默认配置，不能与会切换默认库的评测并行使用。

## 初始资料状态

复用当前七份虚构资料，前五份发布，未审核版本与冲突通知保持草稿。旧版和未来版虽然已发布，仍由有效期排除。上海当前 600 元、北京 450 元正常有效；主题澄清配置启用。

资料不是永久有效。本版用于 2026-10-01 到 2027-01-01 之前；超过窗口，脚本要求维护新版本及正文，不单独延长元数据冒充一致。

本脚本没有冲突/撤回场景切换功能，避免稳定练习库又停在失败场景。冲突及撤回由 `evaluate_knowledge_clarification.py` 在另建的评测库内执行，结束恢复此前默认库。评测库保留最后状态供审计，不能拿其最后状态冒充正常场景。

## 建议自己验证的三个问题

1. “差旅结束后多少个自然日内提交报销？”：正常回答十五天，不应追问地区。
2. “普通员工因公出差，住宿报销上限是多少？”：先澄清；按返回选项传范围和 clarificationMessageId，上海返回 600 元，北京返回 450 元。
3. 打开一次历史失败诊断，解释是引用校验失败、复核否决还是没有资料。旧诊断无需重新执行模型。

对话 API 参数与结构见同目录 README。新的练习账号不会读取原有客户的会话；管理员诊断仍需要管理员身份。
