# 知识库异步索引

## 实现功能与业务规则

- 模型配置新增 `CHAT`、`EMBEDDING` 用途，现有配置迁移为 `CHAT`，两种用途分别维护默认模型。
- Embedding 配置必须声明 1～4096 的向量维度，且流式输出和工具调用能力必须为 `false`。
- 管理员可以异步处理或重新索引文档；接口预检默认 Embedding 模型和 ES 映射后返回 `202`。
- 后台任务依次执行对象下载、Tika 解析、文本分块、分批向量化和 ES 批量写入，成功后文档变为 `READY`。
- 索引失败时文档变为 `FAILED`，只保存固定错误码，并尽力清理可能部分写入的 Chunk。
- `PROCESSING` 文档拒绝重复触发和删除；重新索引使用确定性 Chunk ID 覆盖旧数据。

## 新增类和文件

- `ModelType`、Embedding 模型工厂、动态注册表和默认模型提供器：隔离聊天与向量模型的创建和缓存。
- `ElasticsearchProperties`、`ElasticsearchKnowledgeChunkStore`：配置 HTTPS、CA 和 Basic Auth，管理索引映射、批量写入及按文档删除。
- `KnowledgeDocumentIndexingService`、`KnowledgeDocumentIndexWorker`：负责同步预检、状态推进和异步索引编排。
- `V10__add_model_type_and_embedding_dimensions.sql`：增加 `model_type`、`embedding_dimensions` 和用途查询索引。
- `KnowledgeDocumentIndexWorkerTest`：覆盖成功索引和向量维度不匹配补偿。

## 修改类和文件

- 模型配置实体、DTO、服务和连接测试：支持 Embedding 类型、维度校验和分类默认项。
- `KnowledgeDocumentPersistenceService`：增加 `PROCESSING`、`READY`、`FAILED` 状态推进和并发保护。
- `KnowledgeDocumentServiceImpl`：就绪文档删除前同步清理 ES Chunk，处理中禁止删除。
- `AdminKnowledgeBaseController`：增加异步索引入口。
- `.env.example`、配置示例、README 和数据库字段文档：补充 ES、Embedding 和索引流程说明。

## API 与数据库变化

- 新增 `POST /api/admin/knowledge-bases/{knowledgeBaseId}/documents/{documentId}/index`。
- 模型配置请求和响应新增 `modelType`、`embeddingDimensions`。
- `ai_model_configs` 新增 `model_type`、`embedding_dimensions`。
- ES 索引默认名为 `helpdesk_knowledge_chunks_v1`，Chunk 保存来源、正文、向量、偏移量和模型快照。

## 测试与验证

- 完整测试集共 64 个测试，全部通过。
- 新增测试覆盖聊天/向量默认模型互不影响、后台索引成功、维度异常补偿、ES 映射与 Bulk 协议以及管理端 `202` 响应。
- 未使用真实 Embedding API Key，因此尚未执行完整的模型向量化联调。

## 已知限制与后续工作

- 当前只完成写入链路，尚未实现 BM25、KNN、RRF 融合检索及对话引用。
- ES Bulk 当前按单份文档提交；超大文档后续可以增加分批写入上限。
- 修改默认 Embedding 维度后需要使用新索引名或重建索引，系统会拒绝向维度不一致的旧索引写入。
