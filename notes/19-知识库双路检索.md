# 知识库双路检索

## 实现功能与业务规则

- 管理员可提交自然语言问题，在指定知识库内执行 BM25 全文召回和 KNN 向量召回。
- 查询文本使用当前默认 Embedding 模型生成向量；返回维度必须与 ES 映射一致。
- 每个知识库独立配置单路候选上限、向量相似度下限和最终结果上限，默认分别为 50、0、5。
- 单路候选上限允许 1～200，最终结果上限允许 1～50 且不能超过单路上限；向量阈值必填且允许 0～1。
- 向量相似度过滤始终启用，0 会保留非负相关结果并过滤负相关向量，不再维护额外开关状态。
- KNN 的 `num_candidates` 不对管理员开放，由后端固定为单路候选上限的 2 倍。
- 两路候选以 `1 / (60 + rank)` 标准 RRF 公式去重融合；响应保留生效参数、两路名次和原始分数。
- BM25 检索同一知识库的全部 Chunk；KNN 额外限定当前默认 Embedding 配置 ID 和模型名称，避免混用不同模型生成的向量。
- ES 9.5.4 Basic 许可证不允许调用原生 RRF，本项目采用应用层 RRF，BM25 与 KNN 仍通过一次 `_msearch` 完成。

## 新增类和文件

- `KnowledgeSearchRequest`、`KnowledgeSearchResponse`、`KnowledgeSearchResultResponse`：定义检索请求和可观测的融合结果。
- `KnowledgeChunkSearchHit`、`KnowledgeChunkSearchResults`：承载 ES 两路原始候选。
- `KnowledgeRetrievalService`：生成查询向量、校验维度并执行 RRF 融合。
- `KnowledgeRetrievalException`：对查询向量或 ES 检索故障提供脱敏错误。
- `KnowledgeRetrievalServiceTest`：验证候选去重、RRF 计分和最终排序。
- `UpdateKnowledgeRetrievalSettingsRequest`、`KnowledgeRetrievalSettingsResponse`：定义管理员检索设置接口。
- `V11__add_knowledge_retrieval_settings.sql`：为知识库保存三个查询时参数。
- `V12__require_vector_min_similarity.sql`：迁移历史空阈值并将相似度字段改为非空。

## 修改类和文件

- `KnowledgeChunkStore`、`ElasticsearchKnowledgeChunkStore`：增加一次 `_msearch` 完成 BM25 与 KNN 的能力。
- `AdminKnowledgeBaseController`：增加管理端混合检索调试入口。
- `KnowledgeBase`、服务和响应：持久化、更新并展示知识库级检索参数。
- `GlobalExceptionHandler`：将检索故障转换为 `KNOWLEDGE_RETRIEVAL_FAILED`。
- 管理端集成测试、ES 协议测试、OpenAPI 测试和 README：补充检索接口与行为说明。

## API 与数据库变化

- 新增 `POST /api/admin/knowledge-bases/{id}/search`。
- 新增 `PUT /api/admin/knowledge-bases/{id}/retrieval-settings`，参数修改后无需重新索引。
- 检索请求只包含 `query`；响应包含生效参数、两路候选数及融合后的 Chunk 列表。
- `knowledge_bases` 新增 `retrieval_candidate_limit`、`vector_min_similarity`、`retrieval_result_limit`；Chunk 正文和向量仍只保存在 Elasticsearch。

## 测试与验证

- 单元测试覆盖 `_msearch` 请求结构、两路响应解析和标准 RRF 排名。
- 管理端集成测试覆盖鉴权、请求体和响应结构；OpenAPI 测试确认接口已进入文档。
- Flyway H2 集成测试确认 V11 可以从空库迁移，设置接口覆盖默认值、成功更新和参数关系错误。
- 已在本地 ES Basic 许可证上确认原生 RRF 返回许可证错误，因此未依赖该功能。

## 已知限制与后续工作

- 当前接口用于管理员调试，尚未把检索结果拼接到客户对话提示词。
- 中文 BM25 暂时使用 ES `standard` 分词器，后续可根据召回测试决定是否引入 IK 分词。
- 切换默认 Embedding 模型后，需要重新索引文档，才能恢复这些文档的 KNN 召回。
- 切换向量模型或明显调整分块策略后，应使用真实问题重新评估知识库的相似度阈值。
